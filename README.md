 Student Performance Data Visualization Dashboard

 Project Description

This project analyzes student performance data using Python.

The project uses:

- Pandas
- Matplotlib
- Seaborn
- Plotly

Features

- Load and create student data
- Calculate average marks
- Find highest performer
- Find lowest performer
- Calculate average study hours
- Calculate average attendance
- Create bar chart
- Create line chart
- Create histogram
- Create scatter plots
- Create correlation heatmap
- Create interactive Plotly visualizations

 Dataset

The dataset contains:

- Student ID
- Name
- Gender
- Age
- Study Hours
- Attendance
- Assignments
- Midterm Marks
- Final Exam Marks

Findings

The project compares study hours and attendance with final exam performance.

The analysis shows that students with higher study hours and better attendance generally have better final exam marks.
